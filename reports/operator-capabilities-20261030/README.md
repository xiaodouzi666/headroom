It describes the real restricted AdamWInBackward API, exact import, reviewed owned-module SHA256, preserved original optimizer/groups/hyperparameters and strict prerequisites. It is optional: only an existing AdamW optimizer with measured gradient/optimizer lifetime savings and supported prerequisites may be considered. The fixed module is read with bounded directory descriptors, O_NOFOLLOW and regular-file checks. A missing, changed, linked or oversized source leaves no advertised operator. Metadata construction never imports the optimizer or torch and never reads environment variables.

The catalog describes the standard Docker Lab's read-only /runtime/headroom mount. Current runtime availability and target applicability remain unverified. An external snapshot, user GPU or other runtime needs the corresponding package and module SHA; server source presence does not certify that external runtime. Availability never expands the selected numerical-reference source contract or bypasses its candidate preflight.

The existing model still independently chooses a plan; Super must generate its own integration patch. The existing patch policy, helper runtime guards, sandbox execution, numerical/parameter/memory/throughput checks, 2,000-token bounded diagnosis policy and finite call limits remain.
